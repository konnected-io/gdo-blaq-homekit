# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

HomeKit firmware for the Konnected GDO blaQ garage door opener. C++ on **ESP-IDF v5.4.1** (plain `idf.py`, no PlatformIO/Arduino), target **ESP32-S3, 4MB flash**.

## Build & verify

```sh
git submodule update --init --recursive   # required; build fails with empty submodule dirs
idf.py build
idf.py -p <PORT> flash monitor
```

- ESP-IDF env must be exported (`. $IDF_PATH/export.sh`). `HOMEKIT_PATH` optionally overrides the esp-homekit-sdk location (default `./esp-homekit-sdk`).
- Only `sdkconfig.defaults` is tracked; `sdkconfig` is generated and gitignored. Put config changes in `sdkconfig.defaults`.
- There are no tests. Verify changes by building, then flashing a connected device and checking the serial monitor (use `/flash-verify`).

## Code ownership

- Our code is only `main/`. `components/gdolib`, `components/nvs_wifi_connect`, and `esp-homekit-sdk` are git submodules — do not edit them here.
- Existing code in `main/` isn't uniformly formatted. A hook runs `git clang-format` on changed lines only; don't reformat whole files in unrelated changes.
- Protocol (Security+ 1.0/2.0) changes go upstream to `konnected-io/gdolib` first, then bump the submodule in this repo.

## Gotchas

- `app_wifi_init()` is intentionally called inside the HomeKit task after `hap_add_accessory()` and before `hap_start()` so HAP's event handlers are registered first. Don't move it into `app_main`.
- nvs_wifi_connect only retries Wi-Fi at boot; reconnection is handled by the disconnect handler and `net_watchdog` task in `main/homekit.cpp`.
- Partition table is single-app-large: **no OTA**. Updates ship as a merged bin via ESP Web Tools or serial.
- HomeKit setup code (`251-02-023`) and setup ID are hardcoded and shared by all devices; they're also printed in the README.
- Hardware pins (UART1 TX=GPIO1/RX=GPIO2 inverted, obstruction GPIO5) are set in `main/gdo-blaq-homekit.cpp`.

## Releases & workflow

- Branch from `main`, open PRs against `main`.
- CI (`.github/workflows/build.yml`) builds and merges bins. On a GitHub release, the **tag name is the version**: the bin is named `konnected-gdo-blaq-homekit-<tag>.bin`, uploaded to S3, and the ESP Web Tools manifest is regenerated by `scripts/update-espwebtools-manifest.rb`. The firmware's own `fw_rev` is hardcoded `"dev"` and does not reflect the tag.
